
# 🌍 AI Language Translator

An AI-based language translation web application developed as part of my CodeAlpha Artificial Intelligence Internship.

## 🚀 Features

- 🌍 Translation between multiple languages
- 🔄 Swap source and target languages
- ✍️ Simple text input interface
- 🚀 Translation using an external translation API
- 🔊 Text-to-speech for translated text
- ⚠️ Error handling for invalid input and failed requests
- 📱 Responsive web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Requests
- MyMemory Translation API
- Google Text-to-Speech (gTTS)

## 🌐 Supported Languages

Currently supported:

- English
- Hindi
- Telugu
- Tamil
- Kannada
- Malayalam
- French
- German
- Spanish
- Japanese
